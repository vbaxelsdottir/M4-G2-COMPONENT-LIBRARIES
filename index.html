03 / COMPONENTS

Icon

A shared set of symbols. Used on their own or inside other components.

Standalone preview with an accessible label.

Choose your symbol

Sky is for decorative use on this light background; use Forest or Ink when the icon conveys meaning.

Usage

name selects the symbol, size sets its dimensions, and color accepts a CSS colour or token. Without label, an icon is hidden from screen readers. Inside a labelled button, it is decorative because the button text already describes the action.

Composition

Button now calls createIcon() instead of containing its own SVG drawing. Both playgrounds use the same Icon component.

04 / COMPONENTS

Picture

One image component, three ways to tell a story.

Frame your story

Alternative text describes the photo to people who cannot see it. A caption adds visible context. Text layouts stack on small screens.

Usage

Change src and alt to reuse this component with another photo. The variant controls the layout; ratio controls its crop. Caption uses caption; split uses heading and text. Text is inserted safely with textContent.

The shop and bakery images are copied from the original TÍNT project. Image-only and split layouts reflect its existing patterns; the caption layout is an additional reusable option.

05 / COMPONENTS

BusinessCard

Picture + Icon + Button. Small pieces, working together.

Click the heart to save this example.

A local favourite

Usage

Supply name, src, alt, location, description and href. Choose a variant and initial favorite state. The optional onFavoriteChange(saved) callback lets your page decide what to do when the heart is clicked. This demo keeps state only while the page is open.

06 / COMPONENTS

FormField

A label, input and helpful feedback belong together.

Ask clearly

Usage

Options: label, type, name, placeholder, value, required, disabled, hint, error and onInput(value). Each field gets a unique ID. Errors are connected with aria-describedby and aria-invalid. Validation belongs to the form; the field displays the result. Pass an options array of { value, label } objects to customise the select; this demo uses TÍNT subject choices.

08 / ABOUT THE LIBRARY

One source. Many uses.

Shared rules

The style guide defines colours, type and spacing. Tokens turn those rules into shared CSS values. The component library turns them into reusable code. Documentation and usage rules make this part of a design system.

Clear boundaries

A component receives options and returns an element. It does not read playground controls or save data. BusinessCard combines Picture, Icon and Button; the page handles the favourite callback.

Deliberate adaptation

The palette and patterns come from our TÍNT group project. Controls have visible focus, native semantics and a 44px minimum button target. Caption and compact card layouts extend the original design.

Based on the TÍNT group project. See README.md for the component interfaces, design decisions and submission steps.
